# Miguel Marques Portfolio Clone

This is a clone of Miguel Marques’ personal portfolio website, built with **HTML**, **Tailwind CSS**, and **custom CSS**.

## Features

- Responsive design for desktop and mobile  
- Navbar with smooth scrolling links  
- Hero section with introduction and social links  
- About, Experience, Work, and Contact sections  
- Single profile image used across sections  
- Styled with Tailwind and custom CSS
